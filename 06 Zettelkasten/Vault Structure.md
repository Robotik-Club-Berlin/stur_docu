# Vault Structure

This Obsidian Vault is created to have the least organizational overhead possible. 

### Layers
There are 3 Layers:

1. **Index:** named like the git repos of stur_ws the indexes are broad topics tags are sorted into.  
2. **Topic:** is given to subjects of the StuR project. 
3. **Note:** a atomic information about the subject saved into the Zettelkasten. 

Unlike a strict folder structure notes can relate to different tags and tags can relate to different indexes. You can see those relations better in the graph view (open with menu at the left side)

### Example
From the topic: motor the layers would look smth like this:
1. cad, electronics, firmware
2. motor
3. cnc, cycloidal drive, sls printing ...

from the note: sls printing only the topics are important
1. ...
2. motor, arm shell ...
3. sls printing

from the index: cad the single notes are out of scope
1. cad
2. motor, arm shell, robot model
3. ...

This way the information is organized hierarchically but still can cross reference. 

### Support structure 
To only organize notes into the [[Zettelkasten]] there is a media folder for pdf files or other media. Also the indexes and topics are in different folders to be able to quick view them via file explorer. At last there are the template folder for quick formatting of new notes and the welcome folder to get into the structure of the vault as fast as possible. 

### tags
If you want to further define the category your Note falls into you can add #cad
#electronics #firmware #software #organization #docu
This come in handy if you want to sort in a topic like motor which is sorted to more than one index to only see a certain part of the project.
