# obsidian plugins

Obsidian has a huge plugin platform created by the community to enhance the overall experience. Although to most of the utilities of obsidian is provided by the core application and to many plugins make the vault slow some are a great addition.

To look at the plugins you can go into settings and go to community plugins. 

## Extra Plugins:
There are several Plugins that add extra functionality used by some member to the standard plugins given:
- Git: useful to pull, commit and push changes directly in Obsidian
	- commands:
		- Git: Pull
		- Git: Commit all changes with specific message
		- Git: Push
