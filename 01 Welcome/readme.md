# readme

This is Obsidian vault organizes the documentation of StuR. 
The system in place trys to make documentation fun and usable. Instead of laying down a pdf of 20 pages and bury it 8 folders deep. 

Every new .md note you create is organized in the Zettelkasten. This allows for flow of information across topics. The goal of this vault is that you need as little overhead for creating documentation, research and ideas and anything else as possible. But we also want to find any idea we and others came up with fast and want to know where it fits into the whole project. 

If you want to learn how to use this vault look at link to the [[quick guide]] created by using double brackets like this: [[]]
