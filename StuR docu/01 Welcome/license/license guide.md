# Guide to Project Licenses

This project uses a **Multi-License Strategy** to ensure the work remains open for the global research community while providing a clear path for commercial implementation.

### 1. The Software License: GPLv3

**Applicable to:** All source code in the stur_ws directory.

- **The Philosophy:** "Copyleft." It ensures that the software remains free.
    
- **What you CAN do:** Use it for research, modify it, and share it.
    
- **The Requirement:** If you distribute a version of this software, or a project that includes this software, you **must** also release your source code under the GPLv3.
    
- **Commercial Note:** Most companies want to keep their own code secret. Because the GPLv3 prevents this, commercial entities usually need to contact the author for a **Proprietary License** to bypass these "sharing" requirements.
    

### 2. The Hardware License: CERN-OHL-S v2

**Applicable to:** All CAD files, schematics, and PCB layouts in the stur_ws directory.

- **The Philosophy:** The hardware equivalent of the GPL. It protects the physical design.
    
- **What you CAN do:** Study the designs, manufacture prototypes for research, and improve the hardware.
    
- **The Requirement:** If you manufacture hardware based on these files and distribute it, you must provide the design files (including your improvements) to the recipients under the same CERN-OHL-S license.
    
- **Commercial Note:** If a company wants to manufacture and sell this hardware without sharing their "secret sauce" modifications, they must negotiate a **Commercial Production License**.
    

### 3. The Documentation License: CC BY-NC-SA 4.0

**Applicable to:** Manuals, Wiki pages, images, and explanatory text in the stur_ws directory.

- **The Philosophy:** Attribution-NonCommercial-ShareAlike.
    
- **The "NC" (Non-Commercial):** Unlike the licenses above, this explicitly forbids using the documentation for commercial purposes (e.g., selling a printed manual or using these diagrams in a paid advertisement) without permission.
    
- **The "SA" (ShareAlike):** If you remix or transform this documentation, you must release your version under this same license.

## 🚀 Summary for Users

### I am a Researcher / Student

You are in the clear! You can use, modify, and build upon everything in this repository for your papers, experiments, and personal projects for free. We only ask that you **attribute the original work** to the authors.

### I am a Commercial Entity / Startup

You are welcome to explore the technology for R&D. However, if you intend to:

1. **Sell** a product containing this software or hardware design.
    
2. **Incorporate** this code into a closed-source commercial application.
    
3. **Manufacture** the hardware at scale for profit.
    

**You must contact the author to obtain a Commercial License.** This agreement will grant you the right to use the technology without the requirement to open-source your proprietary intellectual property.
